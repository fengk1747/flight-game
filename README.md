Canyon Postman — a golden-hour mail run. Take off from the home strip, thread the golden rings through the canyon, drop the mail low over the far shore, then fight the headwind home and put her down gently. A Three.js flight game with hand-written flight physics (lift, drag, throttle, stall, banked turns), five mission stages, fuel and damage that force real decisions, canyon gusts and a return headwind, two camera views, a lit instrument panel, and fully synthesized WebAudio sound — no audio or model files, everything procedural.

## Run it

```sh
python3 -m http.server 8080 --directory game  # then open http://localhost:8080
```
